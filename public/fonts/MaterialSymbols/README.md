# Material Symbols subset

`MaterialSymbolsOutlined.woff2` is a subset of Google's Material Symbols
Outlined variable font. It contains the `FILL` and `wght` axes and the
following symbols used by the client:

```text
arrow_drop_down
arrow_left
arrow_right
cancel
chat
chevron_left
chevron_right
close
dark_mode
delete
description
expand_less
expand_more
file_upload
find_replace
folder
folder_open
home
light_mode
menu
not_started
note_add
open_in_full
output
play_arrow
playlist_play
replay
save
subdirectory_arrow_left
sync_problem
zoom_in
zoom_out
```

The subset was generated with the Google Fonts CSS API using its
`icon_names` parameter. When adding another symbol to the client, regenerate
the font with the alphabetically sorted symbol list above.
